# Календарь htmlweb — программа для Windows 10/11

Часы с календарём на панели задач рядом с треем. Клик по часам открывает месяц и ближайшие события из **Google Календаря** и календаря htmlweb — те же данные, что и в MCP-сервисе (`deskcal`: `events`, `event_save`, `notify_push`).

- **Скачать (1.2.2):** https://htmlweb.ru/calendar/win/HtmlwebCalendar.exe
- **Страница и описание:** https://htmlweb.ru/calendar/about.php#download
- **Веб-календарь:** https://htmlweb.ru/calendar/app.php
- SHA256 exe 1.2.2: `EA9515BB2D91FA438909547433F57AD50283960242034650526B0BED964179E0`

## Возможности

- События Google Календаря (OAuth, выбор календарей) и htmlweb; синхронизация с телефоном в обе стороны.
- «Важное событие» — карточка со звуком заранее (настраивается, по умолчанию 30 минут).
- Дни рождения из Google-контактов, праздники, церковные даты.
- Карточка входящего звонка/СМС: СМС-шлюз htmlweb на Android + контакты Google на компьютере.
- Карточки от внешних сервисов через API `deskcal/notify_push` — попадают на рабочий стол за секунды.
- Устойчивость: при недоступности Google события берутся со снимка сервера, недоставленные события досылаются сами; автообновление программы.

Исходники не публикуются. Бесплатно для личного использования; условия — на странице программы.

## API-карточки на рабочий стол (для своих сервисов)

```
GET https://htmlweb.ru/json/deskcal/notify_push?json
    &api_key=КЛЮЧ_ИЗ_ПРОФИЛЯ
    &title=Заказ собран
    &text=Можно забирать с 10:00
    &btn1_title=Открыть&btn1_url=https://example.com/order/123
    &important=1
```
